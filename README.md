# Examples of Feature-Target Pairs $(X, y)$ Across Seminal Deep Learning Architectures

This README provides a detailed breakdown of input feature representations ($X$) and target labels/outputs ($y$) across three foundational deep learning paradigms as presented in their respective research papers:
1. **Deep Residual Learning for Image Recognition (ResNet)**
2. **GPT-3: Language Models are Few-Shot Learners**
3. **Generative Adversarial Networks (GANs)**

---

## 1. Deep Residual Learning for Image Recognition (ResNet)

Deep Residual Networks recast standard feedforward layers to learn residual mappings rather than unreferenced target functions [5]. In supervised computer vision tasks, ResNet operates on explicit input-label pairs.

### Primary Task Formulations

* **Image Classification (e.g., ImageNet & CIFAR-10)**
  * **Input ($X$):** Raw pixel tensor of an image (e.g., $224 \times 224$ RGB image crop for ImageNet [24] or $32 \times 32$ RGB image for CIFAR-10 [42]).
  * **Target ($y$):** Categorical ground-truth class label represented as a discrete scalar or 1-of-$K$ one-hot vector (e.g., one of 1,000 object classes for ImageNet [18, 25] or 10 classes for CIFAR-10 [42]).

* **Object Detection & Localization (e.g., Faster R-CNN with ResNet-101)**
  * **Input ($X$):** Full input image and candidate Region of Interest (RoI) bounding box proposals [63].
  * **Target ($y$):** Sibling outputs consisting of:
    1. Categorical class probabilities ($y_{\text{cls}}$) for predicted object categories [63].
    2. Continuous bounding-box spatial offset parameters ($y_{\text{reg}}$) relative to anchor boxes [63, 79].

* **Internal Block Layer Mapping (Residual Building Block)**
  * **Input ($x$):** Feature representation tensor entering a stacked set of residual layers [12, 15].
  * **Layer Output ($y$):** Element-wise addition of the learned residual function $F(x, \{W_i\})$ and the identity shortcut $x$:
    $$y = F(x, \{W_i\}) + x$$ [15].

## 2. GPT-3: Language Models are Few-Shot Learners

GPT-3 is an autoregressive transformer network trained on token sequences [85]. Rather than task-specific fine-tuning, downstream tasks are framed as language completion via in-context learning [85, 91, 100].

### Primary Task Formulations

* **Self-Supervised Pre-training (Autoregressive Language Modeling)**
  * **Input ($X$):** A sequence of text tokens $(t_1, t_2, \dots, t_{N-1})$ up to the maximum context window of $n_{\text{ctx}} = 2048$ tokens [85, 104].
  * **Target ($y$):** The next token $t_N$ in the sequence, evaluated via cross-entropy loss [85, 112].

* **In-Context Downstream Tasks (Zero-Shot, One-Shot, Few-Shot)**
  At test time, task instructions and $K$ demonstration pairs are provided directly inside the prompt string $X$ without gradient updates [85, 100, 101].

  * **Machine Translation (e.g., English to French):**
    * **Input ($X$):** `"Translate English to French:\n sea otter => loutre de mer\n cheese =>"` [101]
    * **Target ($y$):** `"fromage"` [101]

  * **Arithmetic (e.g., 2-Digit Addition):**
    * **Input ($X$):** `"Q: What is 48 plus 76? A:"` [148]
    * **Target ($y$):** `"124"` [148]

  * **Character Manipulation / Unscrambling:**
    * **Input ($X$):** `"Please unscramble the letters into a word, and write that word: skicts ="` [213]
    * **Target ($y$):** `"sticks"` [85, 213]

  * **Closed-Book Question Answering (TriviaQA):**
    * **Input ($X$):** `"Q: 'Nude Descending A Staircase' is perhaps the most famous painting by which 20th century artist?\nA:"` [218]
    * **Target ($y$):** `"MARCEL DUCHAMP"` [218]

## 3. Generative Adversarial Networks (GANs)

GANs frame generative modeling as an adversarial game between two differentiable subnetworks: a **Generator ($G$)** and a **Discriminator ($D$)** [251, 274].

### Subnetwork Formulations

* **Discriminator ($D$)**
  * **Input ($X$):** Data sample $x \in \mathbb{R}^{|x|}$, drawn either from the real dataset $p_{\text{data}}(x)$ or generated by $G$ as synthetic sample $x' = G(z)$ [253, 254].
  * **Target ($y$):** A scalar probability score in $(0, 1)$, indicating whether $x$ is real ($y \to 1$) or synthetic ($y \to 0$) [254].

* **Generator ($G$)**
  * **Input ($X$):** Random noise vector $z \in \mathbb{R}^{|z|}$ sampled from a simple prior distribution $p_z(z)$ (latent space) [253].
  * **Target / Generated Output ($y$):** High-dimensional synthetic data sample $x' = G(z) \in \mathbb{R}^{|x|}$ designed to fool $D$ [253, 254].

### Conditional & Task-Specific Extensions

* **Conditional GANs (cGANs) & Text-to-Image Synthesis:**
  * **Input ($X$):** Concatenation of noise vector $z$ and conditioning context $c$ (such as class labels or natural language captions) [267, 295].
  * **Target / Generated Output ($y$):** Class- or text-conditioned image sample $x' | c$ (e.g., generating an image of a black bird given caption $c$ = `"This bird is completely black."`) [267, 295].

* **Image-to-Image Translation (e.g., Pix2Pix / CycleGAN):**
  * **Input ($X$):** An image from a source domain $A$ (e.g., a Monet painting or summer landscape) [296, 297].
  * **Target / Output ($y$):** A translated image in target domain $B$ (e.g., a realistic photograph or winter scene) [296, 297].

## Summary Matrix

| Framework | Component / Task | Input ($X$) | Target Output ($y$) |
| :--- | :--- | :--- | :--- |
| **ResNet** | Classification | Image Tensor ($224\times224\times3$) [24] | Categorical Class ID [18] |
| **ResNet** | Object Detection | Image + Region Proposals [63] | Class Label ($y_{\text{cls}}$) + Box Regressions ($y_{\text{reg}}$) [63] |
| **GPT-3** | Pre-training | Sequence of Context Tokens ($t_1, \dots, t_{N-1}$) [85] | Next Token ($t_N$) [85] |
| **GPT-3** | In-Context Learning | Instruction + $K$ Demonstrations + Query Prompt [100, 101] | Completion String [101] |
| **GAN** | Discriminator ($D$) | Real Image ($x \sim p_{\text{data}}$) or Generated Image ($x' \sim p_g$) [253, 254] | Binary Validity Score ($1 = \text{Real}, 0 = \text{Fake}$) [254] |
| **GAN** | Generator ($G$) | Latent Noise Vector ($z \sim p_z$) [253] | Synthetic Image Tensor ($x' = G(z)$) [253] |
| **cGAN** | Conditional Synthesis | Noise Vector ($z$) + Conditioning Text/Label ($c$) [267, 295] | Conditioned Synthetic Image ($x' | c$) [267, 295] |
